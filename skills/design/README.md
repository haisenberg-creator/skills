# Design

Skills for frontend design, UI craft, motion, and 3D visual engineering.

## Skills

- **[taste-skill](./taste-skill/SKILL.md)**: Anti-slop frontend skill for landing pages, portfolios, and redesigns. Infers the right design direction and ships non-templated interfaces.
- **[redesign-skill](./redesign-skill/SKILL.md)**: Upgrades existing websites and apps to premium quality without breaking functionality or rewriting from scratch.
- **[emil-design-eng](./emil-design-eng/SKILL.md)**: Emil Kowalski's philosophy on UI polish, component design, purposeful animations, and micro-interactions.
- **[visual-prototype](./visual-prototype/SKILL.md)**: Interactive visual prototyping for evaluating layouts, components, and design variants.
- **[pick-ui-library](./pick-ui-library/SKILL.md)**: Decision framework for selecting the right component library or design system for a project.
- **[impeccable](./impeccable/SKILL.md)**: Design intelligence engine for AI agents with 24 commands, durable PRODUCT.md truth, and static quality detectors.
- **[landing-page-design](./landing-page-design/SKILL.md)**: Complete landing page design system with intake questionnaires, narrative structure, conversion copy, and visual tokens.
- **[build-awwwards-quality-sites](./build-awwwards-quality-sites/SKILL.md)**: High-concept, motion-led websites featuring GSAP choreography, smooth scrolling, and custom shaders.
- **[video-to-superprompt](./video-to-superprompt/SKILL.md)**: Converts video screen recordings or walkthroughs into precise, builder-ready recreation prompts.
- **[animation-on-scroll](./animation-on-scroll/SKILL.md)**: Scroll-driven animations and storytelling choreography tied cleanly to user scrolling.
- **[gsap](./gsap/SKILL.md)**: High-performance GreenSock animation workflows, timelines, and ScrollTrigger integrations.
- **[threejs](./threejs/SKILL.md)**: WebGL 3D scenes, custom shaders, responsive canvas management, and interactive visual elements.
- **[progressive-blur](./progressive-blur/SKILL.md)**: Layered backdrop blur and gradient mask effects for premium modern UI depth.
- **[3d-ultra-realistic-water](./3d-ultra-realistic-water/SKILL.md)**: Physically-inspired Three.js water shaders with caustics, wave dynamics, and realistic reflections.
- **[3d-underwater-god-rays](./3d-underwater-god-rays/SKILL.md)**: Volumetric underwater light rays and atmospheric fog effects in Three.js.
- **[design-first-ui-prompting](./design-first-ui-prompting/SKILL.md)**: Framework for converting visual design systems into modular, reproducible AI prompts.
